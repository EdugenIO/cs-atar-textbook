# Australian English and textbook house style

Use Australian English in teaching explanations, activities, answers, navigation and downloads: colour, behaviour, organise, analyse, normalisation, authorisation, centre, labelled and enrolment. Use **program** for computer software. Use **licence** as a noun and **license** as a verb.

The owner's explicit house-style exception is **practice/practicing throughout**, including verbs. Use practice, practices, practiced and practicing consistently. This preference takes precedence over the usual Australian noun/verb distinction. Keep labels such as independent practice, practice questions and good programming practices.

Preserve executable identifiers, API names, SQL keywords, file paths, URLs, historical source records and exact attributed quotations. A source link can contain another spelling without changing the textbook's editorial language. Change source material first and rebuild published pages and downloads so copies stay consistent.
